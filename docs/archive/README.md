# Tài liệu lịch sử

Đọc [mục lục hiện hành](../README.md) trước khi triển khai hoặc báo cáo kiến trúc. Các tài liệu dưới đây giữ nội dung lịch sử, được cập nhật liên kết và thêm nhãn lưu trữ ngày 08/10/2026.

| Nhóm | Tài liệu |
|---|---|
| Kế hoạch | [Implementation plan](IMPLEMENTATION_PLAN.md), [backlog](BACKLOG.md), [phân công](BACKEND_TASK_ASSIGNMENT.md), [kế hoạch repository/SignalR](KE_HOACH_REPOSITORY_INTERFACE_SIGNALR.md). |
| Phân tích cũ | [Phân tích dự án](PROJECT_ANALYSIS_AND_TASKS.md), [screen map](CONTRACT_AND_SCREEN_MAP.md), [đề xuất policy](POLICY_DECISIONS.md). |
| Mốc kiểm chứng | [Môi trường](ENVIRONMENT_SETUP_PROGRESS.md), [frontend readiness](FRONTEND_READINESS.md), [hiệu năng](STRUCTURE_AND_PERFORMANCE.md), [cleanup trước](CLEANUP.md). |
| Snapshot code | [Cấu trúc cũ](PROJECT_STRUCTURE_EXPLAINED.md), [function index](FUNCTION_REFERENCE.md) và các file trong `reference/`. |

Function signature và line number tại đây là snapshot trước refactor. Các kế hoạch có thể chứa việc đã hoàn thành hoặc quyết định đã thay thế.
